# Sample Java Project

A collection of **Java coding practice programs** covering fundamental Java concepts, problem-solving techniques, strings, numbers, arrays, and basic programming logic.

This project is created for **Java learning, coding practice, interview preparation, and hands-on programming exercises**.

---

## Overview

This repository contains simple Java programs implemented to practice and strengthen core programming concepts.

The programs cover topics such as:

- Basic Java programming
- Numbers and mathematical operations
- Strings and string manipulation
- Arrays and array operations
- Searching and sorting
- Duplicate element handling
- Palindrome programs
- Prime numbers
- Fibonacci series
- Factorial
- Armstrong numbers
- Number and character frequency
- String reversal
- Anagram and permutation problems
- Basic Java Streams
- Date and time handling
- User input using `Scanner`
- Other common coding interview problems

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/ashokadi34/SampleProject.git
```

Navigate to the project directory:

```bash
cd SampleProject
```

---

## Running the Programs

Open the project in any Java IDE such as:

- IntelliJ IDEA
- Eclipse
- Spring Tool Suite
- Visual Studio Code

Navigate to:

```text
src/test/java/simpleCodePractice
```

Select any Java program and run it using the IDE.

## Requirements

- Java JDK 8 or higher
- Any Java-compatible IDE
- Git

Verify the Java installation:

```bash
java -version
```

```bash
git --version
```
